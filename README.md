# Autowsiper

A cross-platform auto swiper application built with React, Capacitor, and Tailwind CSS.

## Features
- Web interface with touch support
- Mobile-optimized UI with PWA capabilities
- Android and iOS platform support
- Configurable swipe preferences
- Adjustable delay between swipes

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Open iOS project
npm run ios

# Open Android project
npm run android
```

## Platform Support
- Web (PWA)
- iOS
- Android
